Color = electric field magnitude. Contour lines = equipotentials. Axis of symmetry is the left edge (r=0) for point-gap geometries, or the cable's true cross-section for the coaxial-void geometry.

Analytical models (image-charge field solver for point/sphere gaps; Peek's law with air-density & humidity correction; Paschen's law; the ABC void model; a two-layer Maxwell-Wagner solver for transient-vs-steady-state DC field redistribution). Material presets (permittivity/conductivity) are indicative room-temperature reference values — real dielectric DC conductivity is strongly field- and temperature-dependent, especially for HVDC-grade polymers. Order-of-magnitude tool for exploration, not a certified test instrument — see README for assumptions and references.
